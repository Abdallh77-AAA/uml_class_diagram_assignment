# UML Class Diagram Assignment

## Project Overview
This project presents a **School Management System** designed to handle student enrollment, course allocation, and teacher management. The system is modeled using a UML Class Diagram to structure the core entities, attributes, methods, and relationships.

## Project Scope
- **Included**: Student records, Teacher details, Course assignments, and Enrollment processes.
- **Excluded**: Financial management, fee processing, and grading system automation.

## Core Classes
1. **Student**: Handles student information and registration actions.
2. **Teacher**: Manages teacher profiles and course assignments.
3. **Course**: Represents individual subject modules offered by the institution.
4. **Enrollment**: Manages the interaction between students and courses.

## Repository Structure
- `diagrams/`: Contains the editable `.drawio` diagram file and the exported `.png` image.
- `documentation/`: Contains the PDF reports detailing the project description and UML analysis.
